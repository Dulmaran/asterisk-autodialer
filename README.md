# Asterisk Auto-Dialer — obzvon_im ("МИМ"/интернет-магазин)

Скрипт автоматического исходящего обзвона клиентов интернет-магазина
("МИМ") для Asterisk PBX. Читает список звонков из файла и запускает
их через Asterisk **call file**, проигрывая клиенту заранее записанное
голосовое сообщение.

## Как это работает

1. Внешняя система (сайт/CRM) выгружает список звонков в текстовый
   файл `/usr/ftp/calls_im.txt`, формат — одна запись на строку,
   поля через `;`:
   ```
   <номер_телефона>;<путь_к_файлу_фразы>;<id_заказа>
   ```
2. `scripts/obzvon_im` построчно читает файл и для каждой записи
   генерирует Asterisk **call file** — текстовый файл с параметрами
   звонка (транк, контекст, extension, CallerID, переменные), который
   кладётся в `/var/spool/asterisk/outgoing`. Между звонками выдерживается
   пауза (`pause=5` сек.), чтобы не перегружать транк.
3. Asterisk подхватывает call file, инициирует звонок через транк
   `BEELINE_VRN` и передаёт управление в контекст `[obzvon]`,
   extension `1256` (`dialplan/autoobzvon.conf`).
4. Диалплан проставляет `accountcode`/`CDR(realdst)` (для последующей
   сверки в CDR по номеру заказа) и проигрывает клиенту файл
   `${razg}` — ту самую фразу, путь к которой был передан в списке
   звонков.
5. После обработки всего списка скрипт удаляет входной файл
   `calls_im.txt`.

`scripts/obzvon_im.old` — предыдущая версия того же скрипта, оставлена
для истории/сравнения (отличается только логированием прогресса,
логика та же).

## Структура репозитория

```
dialplan/
  autoobzvon.conf             — контекст [obzvon], extension 1256 (используется obzvon_im)
scripts/
  obzvon_im                   — актуальный диспетчер: читает calls_im.txt, создаёт call file'ы
  obzvon_im.old               — предыдущая версия скрипта (для истории)
config-examples/
  pjsip-trunks.example.conf   — пример транка BEELINE_VRN (без реального IP провайдера)
```

## Настройка (что нужно заменить перед запуском)

Реальные номера телефонов (CallerID) и IP-адрес провайдера из
репозитория удалены — вместо них плейсхолдеры.

1. В `scripts/obzvon_im` и `scripts/obzvon_im.old` замените
   `<YOUR_CALLERID>` на реальный CallerID вашей исходящей линии.
2. В `config-examples/pjsip-trunks.example.conf` пропишите реальный
   IP/порт вашего SIP-провайдера (Beeline или другой) и подключите
   транк в `pjsip.conf` — либо заведите свой транк с именем
   `BEELINE_VRN`, которое ожидает скрипт.
3. Подключите диалплан в `extensions.conf`:
   ```
   #include /etc/asterisk/dialplan/autoobzvon.conf
   ```
4. Положите скрипт в `/var/lib/asterisk/agi-bin/obzvon_im`, дайте права
   на выполнение (`chmod +x`) и запускайте вручную или по расписанию
   (cron), когда во внешней системе появляется новый список
   `/usr/ftp/calls_im.txt`.
5. Голосовые файлы (`${razg}` — путь из второго поля списка) должны
   лежать там, где их найдёт Asterisk `Playback()` (обычно
   `/var/lib/asterisk/sounds/...`, без расширения `.wav` в самом пути).

## Зависимости

- Asterisk 18+ с модулем `chan_pjsip`.
- SIP-транк у провайдера (в оригинале — Beeline, транк `BEELINE_VRN`).
- Права на запись в `/var/spool/asterisk/outgoing` и `/var/spool/asterisk/tmp`
  под пользователем `asterisk`.

## Безопасность

CallerID и IP-адрес провайдера вычищены из этого репозитория и заменены
плейсхолдерами. Репозиторий приватный — при добавлении файлов из
продакшн-окружения (реальные списки `calls_im.txt`, записи звонков)
проверяйте их на персональные данные клиентов перед коммитом; списки
звонков и записи не должны попадать в git (см. `.gitignore`).
